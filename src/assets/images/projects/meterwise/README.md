# MeterWise screenshots

These are real screenshots of MeterWise version 1.2 captured in cloud Chrome from https://meterwise-kappa.vercel.app/ on 3 October 2026. The app runs on Vercel with persistent Turso storage. All building readings and tenant names are synthetic demo data.

- energy-overview.jpg: consumption, estimated SGD cost, 100% coverage and daily chart after importing eight missing readings.
- csv-validation.jpg: one valid reading, two duplicate rows and one invalid meter ID.
