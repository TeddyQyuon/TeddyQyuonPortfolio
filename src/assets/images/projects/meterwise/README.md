# MeterWise screenshots

Current screenshots are real cloud Chrome captures of MeterWise version 2.0 from https://meterwise-kappa.vercel.app/ on 3 October 2026 UTC (4 October SGT). Vercel serves the application and Turso persists each demonstration workspace. HDB building metadata is public and real; asset installations, meter readings and maintenance are simulated. The project is not affiliated with HDB or any Town Council.

- energy-overview.jpg: the six-block Singapore estate dashboard after two missing intervals were repaired, showing 100% coverage and separate load, solar and grid energy.
- work-order-audit.jpg: the production maintenance queue after a simulated pump inspection progressed through completion and verification. No contractor is dispatched.
- csv-validation.jpg: retained historical version 1.2 office-building validation screenshot; no longer used by the current case study.
