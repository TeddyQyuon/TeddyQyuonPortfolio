# Technology brand marks

These authentic brand marks identify technologies used in the portfolio's projects and coursework. They do not imply endorsement or affiliation. Concepts without a verified mark remain text-only.

The original collection is from [Devicon](https://github.com/devicons/devicon/tree/master/icons). Newly added Devicon marks are pinned to v2.17.0: Django, FastAPI, PostgreSQL, NumPy, pandas, PyTorch, Tailwind CSS, TypeScript, SQLite, React Router, Vercel, HTML, CSS, SQLAlchemy, scikit-learn and pytest.

Included marks: axios, express, git, github, javascript, materialui, mysql, nodejs, npm, postman, python, react, sequelize, vitejs, vscode.

Stripe, KNIME and MLflow use [Simple Icons v14.10.0](https://github.com/simple-icons/simple-icons/tree/14.10.0/icons). Spotify reuses the existing sourced Spotify mark documented in `../projects/spotify-logo-source.md`. SAS uses the [official SAS media gallery logo](https://www.sas.com/en/news/media-gallery/all-images/sas-logo-blue.html).

Devicon is MIT licensed; Simple Icons is CC0. Brand trademarks remain their owners' property. SAS and Spotify retain their respective brand usage terms.


## 4 November 2026 logo audit

Audited all 39 technology image assets and the social-link glyphs. Existing
Devicon and Simple Icons marks remain canonical sourced artwork; concepts stay
text-only. CSS uses `object-fit: contain` and applies no colour filters.

Replaced Stripe with the unchanged official Blurple wordmark from
https://stripe.com/newsroom/information (official wordmark kit), and GitHub with
the unchanged official Invertocat from https://brand.github.com/GitHub_Logos.zip.
Social links now use GitHub's supplied black/white SVG variants and LinkedIn's
original `LI-In-Bug.png` from its official download:
https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip.
WhatsApp now uses the unchanged 2026 digital green glyph from the official Meta
WhatsApp Brand Resource Center kit, downloaded from
https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/.
No inline or theme-tinted social-brand paths remain. No generic interface symbol
replaces a company.

The remaining technology assets were reviewed for recognisable canonical
geometry and original file colours. They were not all downloaded afresh from
company websites; the pinned upstream sources above remain their provenance.
