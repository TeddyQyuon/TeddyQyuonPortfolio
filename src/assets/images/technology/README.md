# Technology brand marks

These authentic brand marks identify technologies used in the portfolio's projects and coursework. They do not imply endorsement or affiliation. Concepts without a verified mark remain text-only.

The original collection is from [Devicon](https://github.com/devicons/devicon/tree/master/icons). Newly added Devicon marks are pinned to v2.17.0: Django, FastAPI, PostgreSQL, NumPy, pandas, PyTorch, Tailwind CSS, TypeScript, SQLite, React Router, Vercel, HTML, CSS, SQLAlchemy, scikit-learn and pytest.

Included marks: axios, express, git, github, javascript, materialui, mysql, nodejs, npm, postman, python, react, sequelize, vitejs, vscode.

Stripe, KNIME and MLflow use [Simple Icons v14.10.0](https://github.com/simple-icons/simple-icons/tree/14.10.0/icons). Spotify reuses the existing sourced Spotify mark documented in `../projects/spotify-logo-source.md`. SAS uses the [official SAS media gallery logo](https://www.sas.com/en/news/media-gallery/all-images/sas-logo-blue.html).
